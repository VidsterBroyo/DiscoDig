gets fun & interesting stats from a discord dm or groupchat   
check out the [chrome extensions page](https://chromewebstore.google.com/detail/discodig/jdmfjjgfcajnfgibhmbacgfiiikbddoc)   
200+ installs     

to run it yourself:
1. `npm install`
2. `npm blastoff` to build dev version
   - `npm tothemoon` to build prod version
3. in your Chrome browser go to "://extensions," press load unpacked, & select "app" folder
